# Ball Parkour - Collect All Cubes

A 3D platformer where you control a ball to collect cubes while avoiding obstacles and staying ahead of an enemy.

## What I did in this project
- Designed the level layout
- Set up the ball movement physics
- set up the movable green cubes movement physics
- Created the collectible cube system
- Made the gameplay challenging

## How to Play
- Use **WASD** or **arrow keys** to move
- Roll over cubes to collect them
- Avoid the enemy — you have higher top speed, but less torque and acceleration
- Press **Restart** to reset everything and pause the game
- Press **Pause** and **Play** to control the game (press **Enter** to keep pressing it)
