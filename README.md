# Ball Parkour - Collect All Cubes

A 3D platformer focused on movement and collecting cubes.

## What I did in this project
- Designed the level layout
- Set up the ball movement physics
- Created the collectible cube system
- Made the gameplay challenging

## Note about code
This project was built using Unity's visual scripting/prefabs. The focus was on level design and game feel rather than handwritten C#.
